LHC Artefact Management System

Project Overview

The Local Heritage Community (LHC) Artefact Management System is a Python-based application designed to help manage and organise historical artefact records.

The system provides a simple menu-driven interface that allows users to add, update, view and search for artefacts.

Features

Add new artefact records.

Store artefact names, categories, locations and conditions.

Update existing artefact conditions.

View all recorded artefacts.

Search for artefacts by name.

Validate user input.

Display error messages for invalid entries.

Technologies Used

Python

PyCharm

GitHub

Data Structures

The application uses a list of dictionaries to organise artefact information.

Each dictionary stores:

Name

Category

Location

Condition

The main list stores multiple artefact dictionaries.

Permitted Artefact Conditions

Good

Damaged

Under Repair

How to Run the Application

Download or clone this repository.

Open the Python file in PyCharm.

Run the Python application.

Follow the instructions displayed in the main menu.

Main Menu Options

Add New Artefact

Update Artefact Condition

View All Artefacts

Search for Artefact

Exit

Data Storage

Artefact records are currently stored in memory while the application is running. Records are not permanently saved when the program closes.

Permanent data storage is a possible future improvement.
